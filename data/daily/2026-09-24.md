## 分类观察

- **记忆基础设施：** Hindsight 把 retain、recall、reflect 和 memory bank 做成可自托管基础设施，工程价值明显；但长期记忆比普通 RAG 更需要数据分级、租户隔离、保留/删除和投毒测试。
- **控制面与载体：** Ax 负责编排 Agent 工作区，Univer 承载可审查的业务对象，Strands Harness SDK 补齐运行时控制。三者共同指向“Agent 可治理性”，不是单纯增加模型能力。
- **技能与工具供应链：** Superpowers、financial-services、treg 和 CLI-Anything 都会把外部能力接入 Agent；Hooks、社区适配器、凭据代理和费用调用必须有固定版本、命令白名单与服务端授权。
- **学习与优化：** AI Engineering from Scratch 适合构建知识地图，Model Optimizer 适合做部署前性能实验；课程示例和压缩结果都需要独立复现，不能直接迁移到生产。

## 30–60 分钟学习路线

1. **10 分钟：画出记忆数据流。** 标出 retain、recall、reflect、memory bank、数据库、模型提供方和日志之间的数据路径，明确哪些边界可能离开本机。
2. **15 分钟：固定版本并准备隔离环境。** 记录 Hindsight 提交或镜像版本，仅绑定回环地址，在一次性容器或目录中启动；只使用虚构数据，不放入真实账号、客户信息或生产密钥。
3. **15 分钟：做隔离与投毒测试。** 建立两个独立 memory bank，验证跨 bank 查询不能取回内容；把不可信指令作为记忆写入，确认应用不会把它当作高优先级系统指令执行。
4. **10 分钟：验证清理与审计。** 按文档执行 bank 清理或删除并核查存储、日志和备份，记录模型路由、保留策略、失败处理和责任人。
