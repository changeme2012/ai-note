## 分类观察

### AI Agent / Agent Skills

- **连续热门**：`archify`、`scientific-agent-skills`、`claude-plugins-official`。
- **新上榜**：`cursor/plugins`。它与 Anthropic 官方目录一起说明插件规范、目录治理和权限审查正成为新的竞争层。
- 安全提醒：官方目录也要求安装前信任来源；技能与插件可能获得文件、Shell 或外部服务权限，不能只看 Star。

### AI 工程工具

- **值得动手**：`JetBrains/go-modern-guidelines`。仓库小、Apache-2.0、规则明确，30 分钟内就能做一次有对照的 Agent 编码实验。
- `ponytail` 延续高热，适合把 YAGNI 和最小改动写进评审清单，而非全盘复制提示词。

### RAG / 知识库

- **新上榜**：`GitNexus`。浏览器本地建代码知识图谱、提供 Graph RAG Agent，方向与代码理解强相关。
- 主要风险是 PolyForm Noncommercial 许可证；个人学习和商业集成不是同一授权场景。

### 多模态

- `awesome-gpt-image-2` 把提示词工程成模板资产，适合快速复现。
- `OpenMontage` 把视频工具链和生产知识打包为 Agent 系统，能力更完整，但依赖、费用与许可证负担明显更高。

### 模型训练 / 评测

- [marin-community/marin](https://github.com/marin-community/marin) 仍在日榜且采集时刚有推送，但本期更适合作为研究基础设施观察项，没有挤入面向个人学习的 Top 10。

## 今日 45 分钟学习路线

1. **10 分钟：识别信号** — 对比 `go-modern-guidelines`、`cursor/plugins` 和 `claude-plugins-official` 的目标与目录结构。
2. **20 分钟：读规则** — 从 Go 规范或 `ponytail` 中挑三条约束，改写为你的编码 Agent 可执行指令。
3. **15 分钟：做对照实验** — 对同一个小需求分别使用原提示和新规则，比较改动文件数、代码行数、测试结果与解释质量。

## 今日实践任务

制作一张“可审查的 Agent 规则卡”，至少包含：

- 目标与触发条件；
- 允许使用的工具和权限；
- 期望输出格式；
- 失败条件与验收方法；
- 一个真实小任务的前后对比结果。

如果只做一件事：把 `go-modern-guidelines` 的三条规则加入你的编码 Agent，然后记录它是否真的减少返工。
