## 分类观察

- **本地推理**：colibri 把显存不足转化为 VRAM/RAM/NVMe 的调度问题；真正的比较指标应同时包含首 token 延迟、token/s、磁盘占用、缓存状态和输出一致性。
- **多模态生产**：VoiceStudio、YuE、OpenMontage 分别覆盖语音、音乐和视频。三者的工程价值来自中间产物与完整流水线，但内容授权、模型许可和生成成本比功能数量更重要。
- **代码与 Skill 质量门禁**：open-code-review 强调规则和精确率，agent-skills 强调安装供应链。它们都需要内部黄金集验证，不能只看 README 的“安全”或“规模验证”字样。
- **高权限 Agent**：DeskcommCRM 能写业务数据，OpenResearch 能运行远程实验。权限、日志、预算、审批和回滚应先于“自动化程度”设计。

## 30–60 分钟学习路线

1. **10 分钟：选择历史 PR。** 找一个已知真实缺陷的中小型 PR，隐藏最终结论，列出应该检出的缺陷和不可接受的误报。
2. **15 分钟：建立人工基线。** 记录变更文件、关键风险、真实缺陷位置和人工审查耗时。
3. **20 分钟：运行两种审查。** 使用同一模型和上下文，分别运行通用编码 Agent 与 open-code-review，保存完整输出、token、耗时和行级评论。
4. **10 分钟：分类差异。** 把结果标成真阳性、误报、漏报和不可判定，比较精确率、召回率、成本和噪声。
