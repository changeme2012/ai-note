## 分类观察

### 编码 Agent 控制面

- **新上榜**：[Atlas](https://github.com/pacifio/atlas)、[mattpocock/skills](https://github.com/mattpocock/skills)、[Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp)。
- **重回日榜**：[ponytail](https://github.com/DietrichGebert/ponytail)。
- Atlas 解决会话与提交的可追溯性，Chrome DevTools MCP 解决运行时证据，ponytail 与 skills 提供行为规则；四者分别处在不同层，不能互相替代。
- [ECC](https://github.com/affaan-m/ECC) 连续热门，但大而全的 harness 应拆成可评测的小规则，而非一次性迁入。

### 长期 Agent 与权限边界

- [Hermes Agent](https://github.com/NousResearch/hermes-agent) 把持久记忆、自生成技能、定时任务、多平台消息和子 Agent 放在同一运行环境。
- 这类系统的学习价值很高，风险也来自同一处：终端、消息、密钥、自动化和自更新技能组合后会扩大影响范围。优先用测试账号、最小密钥和隔离目录。

### 本地语音与多模态

- [VoiceStudio](https://github.com/debpalash/VoiceStudio) README 提供安装包、Docker、硬件要求、诊断和基准；646 种语言是引擎目录覆盖，不代表每种语言质量相同。
- 应分别记录语音相似度、可懂度、实时系数、显存和授权；声音克隆必须取得声音主体许可。

### 模型与数据

- [TimesFM](https://github.com/google-research/timesfm) 的代码和 2.5 及以前权重为 Apache-2.0，但 3.0 权重使用单独的非商业许可证。选型表必须为代码、权重和数据分别设许可证列。
- [pdf-inspector](https://github.com/firecrawl/pdf-inspector) 连续热门，适合作为文档进入 OCR/RAG 前的第一道分类器。
- [academic-research-skills](https://github.com/Imbad0202/academic-research-skills) 连续加速，但 CC BY-NC 4.0 限制商业使用，研究输出仍需逐条核查引用。

## 今日 50 分钟学习路线

1. **10 分钟：识别控制面** — 对比 ponytail、Atlas、ECC 和 Chrome DevTools MCP，区分规则、会话追踪、harness 与运行时调试。
2. **20 分钟：做权限检查** — 为 Chrome DevTools MCP 和 Hermes Agent 列出浏览器、终端、消息平台、密钥及遥测权限，写出最小授权配置。
3. **20 分钟：跑可验证实验** — 让 Agent 检查一个本地网页的控制台、网络和性能，保存修改前后证据，不访问登录态或个人数据。

## 今日实践任务

做一次可审计的网页性能修复：

- 选择一个无账号、无隐私数据的本地页面；
- 用 Chrome DevTools MCP 记录控制台错误、网络瀑布和性能基线；
- 只选择一个最明确的问题进行修改；
- 重新采集相同指标，记录前后差异；
- 保存代码 diff、测试结果和一条回退命令；
- 如不需要遥测，使用项目文档提供的开关关闭 usage statistics 与 CrUX。

如果只做一件事：让一次 Agent 修改同时留下“为什么改、改了什么、指标是否改善、如何撤回”四类证据。
