## 分类观察

- **代码质量**：open-code-review 用规则降低噪声，agent-skills 用流程约束执行；前者要测召回和误报，后者要检查 Hook 与命令权限，两者都需要项目自己的黄金集。
- **Agent 控制面**：Pi、Atlas、LibreChat 分别强调运行时、检查点和多用户平台。控制面越强，越需要沙箱、审批、凭据隔离、审计日志和一键回滚。
- **本地模型与内容生产**：colibri 解决模型装载，VoiceStudio 解决语音工作流。真实评测应同时记录硬件、首 token/音频延迟、吞吐、存储、模型许可和内容授权。
- **研究与安全工具**：OpenResearch 和 ASC 都适合自动化调用，但前者可能执行第三方实验，后者会解析不受信任 APK；隔离环境与输入来源控制比 Agent 能力更重要。

## 30–60 分钟学习路线

1. **10 分钟：准备隔离仓库。** 创建一个无密钥、无生产数据的小型 Git 仓库，加入一个明确失败的测试和一个可修复缺陷，记录预期改动范围。
2. **15 分钟：启动受限 Agent。** 在 Docker 或微型虚拟机中运行 Pi，只挂载测试仓库，禁用不必要网络，并使用低权限临时凭据。
3. **15 分钟：执行与留痕。** 让 Agent 修复缺陷，保存提示词、工具调用、命令、diff、测试结果、耗时和模型成本。
4. **10 分钟：权限与回滚审计。** 检查是否访问仓库外路径、网络或环境变量，回滚变更，并验证容器销毁后凭据和工作文件不残留。
