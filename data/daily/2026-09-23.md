## 分类观察

- **控制面与运行时：** Ax 和 Substrate 连续上榜，说明热点正从单个 Agent 应用转向工作区生命周期、网络出口、暂停恢复与多租户隔离；两者仍在快速演进，暂不宜直接承担生产负载。
- **工作载体：** Univer 把 Agent 引入表格、文档与幻灯片，价值在于可审查的业务对象；真正的门槛是版本冲突、权限和服务端动作校验。
- **技能工程：** Superpowers、Impeccable、video-use 和 claude-code-templates 展示了技能从提示词走向 Hooks、脚本、二进制和多客户端分发，供应链治理已成为功能本身的一部分。
- **垂直与工具路由：** financial-services 需要专业签署，treg 需要凭据和费用边界；垂直知识与工具便利都不能替代服务端授权。
- **代码记忆：** codebase-memory-mcp 把代码索引放到本地知识图，但长期后台进程、自动修改配置和源码索引范围必须透明可撤销。

## 30–60 分钟学习路线

1. **10 分钟：列安装面。** 对 Superpowers、Impeccable 和 claude-code-templates 分别列出会写入的目录、Hook、脚本、MCP、二进制和外部服务，不执行安装。
2. **15 分钟：固定来源并做静态检查。** 记录仓库提交 SHA、许可证与第三方组件来源，检查安装脚本、Hook 清单、网络下载、遥测和卸载路径。
3. **15 分钟：最小权限沙箱测试。** 在一次性仓库中只启用一个技能，禁用真实凭据和生产网络，观察其文件修改、子进程、端口、环境变量和 Agent 配置变化。
4. **10 分钟：形成准入卡。** 写明允许版本、文件写入、网络目的地、回滚步骤、审查责任人和拒绝条件，再决定是否进入团队模板。
