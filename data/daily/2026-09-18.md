## 分类观察

- **安全与审查：** security-audit-skill 和 open-code-review 继续证明，覆盖、规则和验证比“多问模型一次”更有工程价值。
- **Agent 控制面：** BrowserSkill、Octop 与 Coder 分别处理浏览器会话、多人控制面和隔离工作区，权限治理正在成为 Agent 产品核心。
- **规格与技能：** OpenSpec、ECC 和 agent-skills 都在把对话中的临时约束变成可版本化资产；关键仍是能否测试、审查和卸载。
- **知识工作插件：** knowledge-work-plugins 的可读 Markdown 结构降低了审查成本，但连接器和组织数据权限才是部署难点。
- **编码 Agent：** Claude Code 保持活跃，但许可、数据收集与终端执行权限需和开源技能本身分开判断。

## 30–60 分钟学习路线

1. **10 分钟：选择小变更。** 在玩具仓库定义一个可快速完成的功能，列出成功条件、非目标和安全边界。
2. **15 分钟：编写规格。** 用 OpenSpec 创建需求、具体场景和验收标准，关闭非必要遥测，并先审查规格。
3. **20 分钟：隔离实现。** 在独立分支或 Coder 工作区让 Agent 实现变更，限制凭据、网络和写目录，保存命令、diff 与测试结果。
4. **10 分钟：核验回滚。** 将测试证据逐条映射到规格场景，记录未覆盖项，回滚并确认没有遗留密钥、进程或外部副作用。
