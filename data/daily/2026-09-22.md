## 分类观察

- **运行时与控制面：** Ax 描述声明式控制面，Substrate 提供隔离运行时，二者形成较完整的 Agent 平台分层；但都处于快速演进阶段，热度不等于生产成熟度。
- **工具与技能供应链：** treg 集中保管凭据并代理调用，claude-code-templates 与 video-use 则把第三方脚本、Hooks、MCP 和服务带入开发环境；来源固定、最小权限和可撤销凭据比安装便利更重要。
- **Agent 进入现有工作载体：** Univer 把 Agent 带入 Office 文档，Agent-Native 把 Agent 带入应用状态与审批，二者都要求服务端权限校验和可审查变更记录。
- **垂直与长期上下文：** financial-services 和 ai-memory 分别聚焦高风险垂直工作流与持久记忆；前者必须专业签署，后者必须验证脱敏与清除。
- **连续基础设施：** Cua 虽未进入本期采集到的日榜，但仍活跃；其桌面控制、云计费和模型许可仍是采用前的主要门槛。

## 30–60 分钟学习路线

1. **10 分钟：读懂控制面与运行时边界。** 对照 Ax 的 Workspace、Task、Gateway 与 Substrate 的 Sandbox、认证、出口控制，画出控制面、数据面、模型服务和外部工具的信任边界。
2. **15 分钟：写最小声明式清单。** 参考 [Ax 示例](https://github.com/google/ax/tree/main/examples)写一个仅允许访问代码仓库与模型 API 的 Workspace、Task、Gateway 草案；使用虚构 Secret 名称，不放真实凭据。
3. **15 分钟：做静态越权测试。** 向任务加入未批准域名、额外端口和调试 SSH，逐项记录策略应拒绝的位置；检查出站白名单、密钥注入与暂停恢复是否有审计事件。
4. **10 分钟：定义生产门禁。** 列出版本固定、资源上限、镜像来源、租户隔离、日志脱敏、紧急停止与回滚条件，并标明两项目目前不直接承载生产工作负载。
