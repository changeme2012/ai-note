## 分类观察

- **Agent 应用层：** Cua 负责计算机操作基础设施，Agent-Native 负责可视状态与审批；前者的难点是桌面隔离和计费，后者的难点是动作授权与多人状态一致性。
- **记忆与交接：** ai-memory 把记忆落到可审计 Markdown，并提供跨 Agent 交接；这比不可见的托管记忆更容易检查，但也把敏感上下文持久化风险带到文件、Git 和备份层。
- **垂直工作流：** financial-services 和 AutoClip 都有明确可执行流程；金融输出需要专业签署，视频处理需要版权和隐私复核，不能因自动化程度高就跳过人工门禁。
- **隔离与离线：** Coder 管理开发环境，Project NOMAD 管理离线知识节点；二者的价值都依赖网络、身份、更新和存储策略，而不是“自托管”标签本身。
- **工程控制面：** security-audit-skill、json-render 和 agent-skills 没有进入本次日榜，但分别代表独立验证、受约束输出和标准流程，仍适合作为可复现练习对象。

## 30–60 分钟学习路线

1. **10 分钟：准备隔离样本。** 创建只含虚构架构、待办和失败方案的一次性仓库，列出允许进入记忆的数据类别，绝不放真实凭据或客户数据。
2. **15 分钟：启动最小服务。** 按 [README](https://github.com/akitaonrails/ai-memory#docker)固定 v2.4.0，以零 LLM 模式、非特权用户和 `127.0.0.1` 绑定启动容器；检查端口和数据卷。
3. **15 分钟：跨 Agent 交接。** 在第一个兼容客户端记录设计决定和失败方案，再从第二个客户端读取交接；检查 Markdown 事实源、检索结果与认领状态。
4. **10 分钟：审计与清除。** 查看审计日志与捕获字段，注入伪造密钥验证脱敏，再执行项目级清除并检查文件、索引和备份残留。
