## 分类观察

- **控制面与记忆：** Paperclip 管组织、预算和审批，Hindsight 管长期记忆，Ax 管工作区与出口。三个项目共同指向 Agent 平台化，但治理面越完整，密钥、数据保留、费用和应急停止的验证责任也越重。
- **真实执行面：** Mobile MCP 把 Agent 扩展到手机，Claude Code Action 把 Agent 扩展到 CI。前者的边界是设备和个人数据，后者的边界是仓库写权限与工作流令牌；两者都不适合用默认全权限直接试跑。
- **业务对象与工程学习：** Univer 提供可审查的 Office 对象，AI Engineering from Scratch 提供知识地图；一个适合产品化原型，一个适合学习，但都需要区分开源核心、商业能力与生产质量门槛。
- **成熟栈与优化栈：** TensorFlow 的复现路径成熟，Model Optimizer 更专注 NVIDIA 部署优化。前者的难点是版本矩阵，后者的难点是 0.x 变化、GPU 环境和任务级质量回归。

## 30–60 分钟学习路线

1. **10 分钟：列出 Mobile MCP 的能力与资产。** 把设备、应用、账号、剪贴板、定位、截图、日志和云端设备列成资产表，并标出读取、修改和删除类工具。
2. **10 分钟：固定版本并准备空白模拟器。** 不使用 `@latest`；固定 npm 版本或提交，只启动一个无个人账号、无真实通知和无生产应用的模拟器。
3. **20 分钟：运行受限测试旅程。** 只开放列设备、启动测试应用、列元素、点击和截图；完成一个虚构登录表单，记录每个工具调用、屏幕状态和意外权限请求。
4. **10 分钟：验证清理与拒绝条件。** 卸载测试应用、清除剪贴板和定位覆盖，关闭模拟器；确认没有云设备占用、日志残留或宿主配置漂移。
