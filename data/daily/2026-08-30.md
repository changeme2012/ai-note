## 分类观察

### Agent Skills 与垂直工作流

- **连续热门**：archify、scientific-agent-skills。
- **新上榜**：last30days-skill 把“最近 30 天”变成可重复研究流程；patent-disclosure-skill 则展示了技能如何进入高约束专业文档场景。
- 垂直技能的真正壁垒不是提示词长度，而是数据来源、证据链、失败边界、可编辑中间产物与人工复核点。

### 数据获取与代码上下文

- crawl4ai 重回关注，GitNexus 重回本站 Top 10；一个处理网页上下文，一个处理代码结构。
- 二者都提醒我们：抓取或建图只是中间层，最终仍要验证覆盖率、时间、来源和解析遗漏。

### Agent 运行时与模型入口

- OpenMAIC 连续加速，livekit/agents 新上榜，说明可交互 Agent 正从聊天框扩展到课堂、语音、视频和电话。
- freellmapi 的上手成本低，但“免费模型入口”不等于稳定、私密或可用于生产；敏感数据不要交给无法确认处理条款的上游。

### 具身智能

- microduck_rl 是今天小体量但学习信号很强的项目：README 给出环境、训练命令、预训练权重、无 GPU 路径和 sim-to-real 说明。
- 软件流程可低成本学习，完整硬件复现则需要设备、校准和安全空间，不能按普通 Python 项目估算上手成本。

## 今日 50 分钟学习路线

1. **10 分钟：画出完整链路** — 用 last30days-skill、crawl4ai、GitNexus 和 livekit/agents 分别标记上下文获取、结构化、代码理解与实时交互层。
2. **20 分钟：做证据检查** — 任选 3 个近期网页，记录 URL、发布日期、原文证据和它能支持的结论，检查聚合结果有没有偷换时间或因果。
3. **20 分钟：跑最小管线** — 用 crawl4ai 提取 3 个页面的标题、日期、正文与链接，再让模型生成逐点带来源的五条摘要。

## 今日实践任务

做一个“带引用的最近 30 天研究”小管线：

- 选择一个具体 AI 主题；
- 找 3 个最近 30 天内的一手或高质量来源；
- 保存标题、URL、发布日期和支持结论的正文证据；
- 生成不超过 5 点的摘要，每点都附原始链接；
- 逐条标注“来源直接支持 / 仅能间接推断 / 无法支持”，删除最后一类结论。

如果只做一件事：不要追求抓取数量，先让 3 个来源的日期、证据和结论完全对得上。
